# 首场战斗战损对比 — 项目计划书

> v0.4

---

## 1. 背景

游玩塔2 时，主观上觉得**第一场战斗**比塔1更容易掉血、掉得更多。  
想用游戏数据验证这个感受是否成立。

---

## 2. 目标

比较塔1与塔2：在**初始卡组**打**Act 1 弱怪池首场战斗**时，

- 「即使绝对最优出牌，也**必定吃战损**」的**加权**比例是否塔2更高；
- （可选）**加权期望战损**与战损分布是否塔2更差。

玩家模型：知晓牌序、**绝对最优决策**（对应 SL 下的理想操作）。

---

## 3. 做法

- **不与游戏本体联动**，不做真实游玩数据采集。
- 数据：初始卡组（你提供）+ 弱怪意图等（wiki / 已录入 JSON，格式见 `docs/游戏数据格式.md`）。
- 对每条**抽牌路线** ω（各回合上手组合 + 出现权重 w(ω)）求 **D(ω)** = 最优总战损。
- 汇总见 `docs/求解器设计.md` §1（**不等权**）。

---

## 4. 核心概念

| 用语 | 含义 |
|------|------|
| 战损 | 本场战斗失去的 HP；掉 1 点即计战损 |
| 抽牌路线 ω | 从开局到击杀，各回合上手组合的序列 |
| w(ω) | 该路线在洗牌规则下的概率权重（组合多重数乘积） |
| D(ω) | 该路线下最优出牌的总战损 |
| 必定吃战损 | D(ω) > 0 |
| 加权必伤概率 | ∑_{D>0} w(ω) / ∑ w(ω) |

---
